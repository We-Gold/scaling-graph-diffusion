# Data

Datasets are not stored in git. Parts read from this folder unless noted.

| Path | Used by | Source | How to get it |
| --- | --- | --- | --- |
| `zinc250k/raw.csv` | `scale_mgd` | Kaggle `250k_rndm_zinc_drugs_clean_3.csv` | Manual download. The first run writes the split and `processed_train.pt` (about 2.3 GB) |
| `planar/planar_64_200.pt` | `scale_mgd` | SPECTRE (6.5 MB) | Automatic |
| `ego/Ego.pkl` | `scale_mgd` | EDGE (7.7 MB) | Automatic |
| `redditwalk/soc-redditHyperlinks-{body,title}.tsv` | `redditwalk` | [SNAP](https://snap.stanford.edu/data/soc-RedditHyperlinks.html) (319 MB + 369 MB) | Manual `curl -O`, see `redditwalk/README.md` |
| `redditwalk/giant_component_nodes.txt`, `giant_component_{body,title,combined}.csv`, `wcc_stats.json` | `redditwalk` | | Made by redditwalk steps 01-02 |
| `redditwalk/subreddit_descriptions*.tsv`, `redditwalk/giant_component.csv` | `redditwalk` | | **Missing** (Hien Pham, probably Turing) |
| `redditwalk/subgraphs/{500_reddit_subgraphs_200,300_reddit_subgraphs_400,200_reddit_subgraphs_800}.pt` | `redditwalk`, 6.4 | | **Missing** (David Dechantsreiter). Rebuild with step 08 once `giant_component.csv` exists |

`SGD_DATA_ROOT` overrides this folder for `scale_mgd`. SLURM nodes need internet for automatic downloads, or
copy the files here first.

Stored elsewhere:

- `sparserdiff/data/{qm9,ego}/`: QM9 (no H, 364 MB) and Ego (126 MB) for SparserDiff, downloaded automatically.
- `viz/web/data/digress_moses_sample/`: committed (1002 npz files, about 0.3 MB in git). Denoise steps and
  `step_00_original` are original MQP output. Forward steps 1-500 were regenerated by
  `viz/web/scripts/regenerate_forward.py`. See `viz/web/README.md`.
- `benchmarks/edge_sampling` and `benchmarks/scaling` generate random input graphs from a seed.
